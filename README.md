# 🎓 StudyQuest

> A student productivity and study planning web application designed to help students organize subjects, manage tasks, track study progress, and stay consistent with their goals.

🌐 **Live Website:** https://studyquest.freedev.app

---

## 📌 About the Project

**StudyQuest** is a web-based study management application created to make academic planning easier and more organized.

The application allows students to create subjects, add study tasks, manage priorities, track completed tasks, set daily goals, and use a study timer.

The project was developed as a college project while learning **PHP, MySQL, HTML, CSS, JavaScript, and Bootstrap**.

---

## ✨ Features

- 🔐 User Registration and Login
- 📚 Add and Manage Subjects
- 📝 Create and Manage Study Tasks
- ⭐ Task Priority Management
- ✅ Mark Tasks as Completed
- 📅 Study Planner
- 📊 Progress Tracking
- 🎯 Daily Study Goals
- ⏱️ Study Timer
- 📈 Study Session Tracking
- ⚙️ User Settings
- 🌙 Modern Dark UI
- 📱 Responsive Design
